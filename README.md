## Overview

ChowCentaur uses a recurrent neural network trained on circuit captures of an original Klon Centaur to reproduce the pedal's complex clipping and frequency response without traditional circuit modeling.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ChowCentaur** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **RNN Model** | Recurrent neural network captures time-dependent Centaur nonlinearity |
| **Gain Control** | Emulates the Centaur's gain pot with blend and treble interaction |
| **Clean Blend** | Parallel clean path matches original Centaur clean-signal blend circuit |
| **Output Level** | Unity-gain output stage with headroom matching original hardware |
